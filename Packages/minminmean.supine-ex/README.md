# Gorone System EX (Supine EX)

ごろ寝システム（`minminmean.supine`）にポーズを追加するデータパッケージです。

## 中身

- ポーズのアニメーションクリップ 6 本（MJI / DISK / KJI / KJI_ZNK / SNK / SRAG）
- メニュー用アイコン
- ポーズパックの定義（`SupineExPosePack.asset`）

コントローラーもプレハブもコードも持ちません。ポーズの組込はごろ寝システム本体が行います。

## 使い方

1. このパッケージを導入する
2. `Tools > MinMinMart > Supine Combiner` を開く
3. アバターを指定して組み込む

**EX 専用のウィンドウはありません。** 本体のウィンドウがパッケージを見つけて、メニューに `Ex Poses` を追加します。

パッケージを外せばポーズも消えます。

## v5.0.0 での変更

EX 版は以前、本体のアニメーターとプレハブを丸ごと複製した「バリアント」として動いていました。本体を直すたびに同じ修正を EX 側へ写す必要があり、写し漏れも起きていました。

v5.0.0 からはポーズパックの仕組みに乗り換え、データだけを持つ形になっています。

移行にあたっての注意です。

- `Tools > MinMinMart > Supine Combiner (EX)` は無くなりました。本体のウィンドウを使ってください
- 組み直しが必要です。既存の生成物はそのままでは新しい形になりません
- ポーズの `VRCSupine` の値（51〜56）は従来と同じなので、メニューの保存済みの選択はそのまま使えます
